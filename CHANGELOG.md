# Changelog

All notable changes to this project are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versions follow [Semantic Versioning](https://semver.org/).

## [2.1.0] — 2026-10-19

Visual and interaction overhaul. The product is now presented as **SongStub /
曲票**; the repository keeps the name `songup-queue` so existing links and
clones keep working.

### Added

- **Ticket-stub design language.** Every list row is a ticket with two punched
  notches and a dashed tear line; the currently playing song is a torn ticket
  lying at a slight angle. Notch colour is inherited from the parent surface, so
  the same component works on both the dark stage and the light page.
- **QR join card** on the host page, with a large address and a copy button.
  Backed by `qrmini.py`, a standard-library QR encoder (byte mode, ECC-M,
  versions 1–10), because the project's rule is zero third-party dependencies.
- **Ticket holder** on the guest page: one slot per allowed song, filled as you
  spend them. Replaces a single line of text that could not show "how many out
  of how many".
- **Progress bar and remaining time** for local media, shown on the ticket's
  "remaining" column.
- **Wait estimate** on the guest page: "还要等 N 首轮到你", derived from the
  position of the guest's first entry.
- **Connection indicator** on the host page (`已连接` / `重连中…`).
- **Keyboard shortcuts** on the host page: `Space` / `→` next, `M` mute, `C` clear.
- **Brand assets**: mark, wordmark, favicon, 1280×640 social card, and a
  system diagram. All generated by `tools/make_brand.py` and
  `tools/make_diagram.py`.
- **`verify/responsive.cjs`**: six widths × two pages, checking horizontal
  overflow, target size, contrast computed from rendered styles, external
  requests, `prefers-reduced-motion`, and QR presence.
- **`tests/test_qrmini.py`**: golden matrices and structural assertions for the
  QR encoder, with no third-party dependency.

### Changed

- Guest page rebuilt on a light paper surface (`#FBF5E9`); host page rebuilt on
  a dark stage surface (`#14100D`). Brass `#E0A33F` is the single accent shared
  by both.
- Typography: serif display for names and ticket titles, system sans for UI,
  monospace for serials and counters. All numbers use tabular figures.
- Queue rendering only touches the DOM when the queue contents change. It
  previously rebuilt the list on every poll, which restarted the entry animation
  and made the list flicker every 2.5 seconds.
- The host page's empty-state copy now reflects `queue_length` instead of always
  claiming the queue is empty.

### Fixed

- **Stale `ended` events.** A `<video>` element being torn down can still fire
  `ended` after `teardown()`, which advanced the queue a second time and skipped
  a song. Player callbacks now carry a generation counter and ignore events from
  a previous generation.
- **320 px overflow** on the host page: a bare `1fr` grid track keeps its
  min-content floor, so the 16:9 stage forced the column to 431 px. Now
  `minmax(0, 1fr)`.
- **Footer link target size**: the single inline link was 15 px tall, below the
  24 px minimum in WCAG 2.5.8. It is now an inline-block with padding.
- **Contrast**: several muted tokens sat between 2.7:1 and 4.0:1 on their
  surfaces. All text now clears 4.5:1 (worst measured sample 5.18:1 across 598
  samples).
- Missing favicon (previously a 404 on every page load).

### Documentation

- `docs/design/DESIGN.md`: palette with measured contrast, type scale, the
  ticket component's construction, the interaction change list, the selector
  contract that must survive a redesign, and the acceptance criteria.
- README rewritten around the new name, with the change table, the verification
  gates and their measured results, and an asset inventory.
- `NOTICE.md` records what came from upstream and what changed.

## [2.0.0] — 2026-10-17

- Rewrote the queue engine and both front ends.
- Added a real player: YouTube IFrame API, Bilibili iframe, local `<video>`,
  rebuilt on every `seq` change.
- Fixed a stored XSS: song titles were interpolated into `innerHTML`.
- Quota changed to occupancy semantics (a playing song still holds a slot).
- Dedup extended to cover the currently playing track.
- Cooldown now records the song that actually finished, not the one before it.
- `clear()` also clears the cooldown table and the fallback cursor.
- `current_source` distinguishes `queue` / `fallback` / `empty`.
- Disabled debug mode and the hard-coded secret key.

## [1.0.0] — 2026-10-17

- Initial version: fair dedup queue, quota, cooldown, fallback tracks.
- Playback was described in the README but not implemented.
